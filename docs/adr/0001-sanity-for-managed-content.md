# Sanity pro spravovaný obsah

Toto rozhodnutí nahradilo [ADR 0002: JSON soubory pro spravovaný obsah](0002-json-for-managed-content.md).

## Consequences

Sanity už není zvoleným zdrojem čteného obsahu webu. Její dočasné použití pro zapisovací akce akcí během migrace popisuje ADR 0002.
