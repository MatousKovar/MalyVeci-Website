# Navrhnout lepší mobilní navigaci

Současné menu pod ikonou se třemi čárkami působí jako základní nehotový popup a vizuálně nesedí ke zbytku webu.

Nejdřív připravit několik rychlých variant, alespoň boční vysouvací panel a celoobrazovkové menu. Porovnat je přímo na mobilní šířce a jednu vybrat před implementací.

Hotová navigace musí:

- používat černou a červenou vizuální řeč současného webu,
- mít dostatečně velké odkazy pro ovládání palcem,
- jasně ukázat, jak menu zavřít,
- zavřít se po výběru odkazu,
- během otevření zabránit posouvání stránky pod menu,
- fungovat s klávesnicí a čtečkou obrazovky.

Tento ticket nepatří do implementace administračního režimu.
